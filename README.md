# Portfólio de Enzzo Gomes

Portfólio bilíngue (PT/EN) com projetos de dados, BI, IA e desenvolvimento full stack.

**[Ver online](https://portifolioenzzogomes.vercel.app)**

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=white) ![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white)

## Destaques

- Conteúdo em português e inglês, com troca de idioma na própria página
- Galeria de projetos com stack, demonstração e código de cada um
- HTML, CSS e JavaScript puros, sem etapa de build

## Estrutura

```
index.html            Página única
assets/css/           Estilos
assets/js/main.js     Conteúdo dos projetos, idiomas e interações
assets/images/        Foto de perfil e capturas de tela
```

## Como rodar

```bash
python3 -m http.server 8000
```

Depois abra http://localhost:8000.
